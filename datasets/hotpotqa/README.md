# HotpotQA: ten-question teaching subset

Ten real questions from the **distractor / validation** split of
[HotpotQA](https://hotpotqa.github.io/): five comparison and five bridge questions.
Bridge questions require connecting facts across documents. This is a small,
deliberately balanced teaching sample, not a representative benchmark or live city guide.

For all **7,405 development questions**, use the [full-development guide](../HOTPOTQA_DEV.md).
It loads each question's candidates separately; this small bundled demo is unchanged.

## Files

- `knowledge/`: exactly **100 candidate paragraph documents**, including distractors.
  Only point `HARNESS_KNOWLEDGE` here, not at this parent directory.
- `questions.json`: questions and their candidate filenames; no gold labels.
- `answers.json`: reference answers, question types/difficulty and supporting facts.
  For humans and evaluators only; never include this in model input.
- `source.json`: the ten selected original records, including their gold labels.
  Saved for offline reproducibility, not for retrieval or model input.
- `manifest.json`: source, license, selection rule, snapshot SHA-256 and document map.

The numbered sentences in each paragraph correspond to HotpotQA's zero-based
sentence IDs. Citation IDs returned by the harness instead use character-window
offsets, such as `q01-p01.txt#char-0`; they are not sentence-level evaluation labels.

## Try the first question

From the repository root, run
`HARNESS_KNOWLEDGE=datasets/hotpotqa/knowledge python3 -m agents.teaching.cli rag-mock "Were Scott Derrickson and Ed Wood of the same nationality?"`.

This offline demo quotes retrieved evidence, not an answer. With your LLM provider
configured, omit `rag-mock` to ask the real agent the question. Open `questions.json`
for the remaining nine. Each one-shot run starts with fresh conversation history.
Existing approval checks still apply; no live-model calls are needed to use the corpus.

The default fictional observatory corpus is unchanged. Keep this dataset outside
the writable workspace. Answer-key separation is a tool-access boundary in this
educational harness, not protection from tools you add with unrestricted filesystem
access or a workspace configured to include this dataset's parent directory.

## Reproduce or refresh

No download is needed to use the bundled subset. To reproduce it offline into a
new directory, run
`python3 -m evaluation.hotpotqa.prepare --input datasets/hotpotqa/source.json --output datasets/hotpotqa-rebuilt`.
The generated dataset files are deterministic for the same input and script version.
This README is documentation, not a generated artifact.

To fetch a fresh preview instead, run
`python3 -m evaluation.hotpotqa.prepare --output datasets/hotpotqa-fresh`.
The script uses the public [Hugging Face mirror](https://huggingface.co/datasets/hotpotqa/hotpot_qa)
and its [preview endpoint](https://huggingface.co/docs/dataset-viewer/first_rows),
since the original download host was unavailable during preparation. No account,
API key, datasets library, embeddings or training is required. It refuses truncated
preview cells and insufficient examples rather than silently dropping evidence.
The preview is a mutable upstream service; the bundled snapshot and checksum pin
this lesson's data, not the future contents or availability of the remote endpoint.
`--input` also accepts the original development-set JSON from the HotpotQA website.
Existing destinations are never overwritten; choose a fresh directory if needed.

## Learning and evaluation limitations

- The shared corpus contains candidates for all ten questions, not just the ten
  candidates supplied for an individual official distractor example. Results are
  **not directly comparable to official benchmark scores**.
- Keyword retrieval returns at most three 800-character windows per call. Some
  questions need multiple searches; a high keyword score is not evidence of truth.
- The 100 files exactly fill the current directory-entry budget. Do not add extra
  files inside `knowledge/`; metadata and this README intentionally live outside it.
- This shared-corpus demo does not score answers. The separate
  [single-agent baseline](../HOTPOTQA_BASELINE.md) uses the same IDs with each
  question's own candidates, scores answers/evidence, and records resource use
  for the later multi-agent comparison. Ten examples cannot establish general quality.
- Original human-provided labels are preserved, not generated by an LLM. Public
  benchmarks may be present in a model's training data; require retrieved evidence
  rather than interpreting a correct answer alone as proof of successful retrieval.
